# Hu Jiao — Personal Portfolio

A responsive bilingual personal profile website for Hu Jiao, available in English and Simplified Chinese.

## Preview locally

Open `index.html` directly in a browser, or serve the directory with any static file server.

## Built with

- Semantic HTML
- Responsive CSS
- Vanilla JavaScript
- Self-hosted Manrope with native Chinese font fallbacks

## Pages and maintenance

Home, Experience, Projects, and Photography are separate HTML pages.
Shared copy is in `site-content.js`; current styles are in `site.css`.
See [中文维护说明](WEBSITE-GUIDE.md) for editing text and adding photography albums.
